# Impact of Social Media & Gaming on Daily Mood

Welcome to my project exploring how social media and gaming habits impact our daily mood!

## What is This Project About?

This research investigates the relationship between daily mood ratings and time spent on social media platforms and gaming. By analyzing real-world data, we aim to understand if increased screen time is associated with mood changes (either positive or negative).

## Technologies Used

This project is primarily built using:

- **Jupyter Notebook (Python):** For data cleaning, analysis, and visualization.
- **Markdown:** For documentation and reporting findings.

_See the full code and data on [GitHub](https://github.com/Ojas2011/Impact-of-Social-Media-Gaming-on-daily-mood)._
